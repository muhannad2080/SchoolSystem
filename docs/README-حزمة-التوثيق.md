# حزمة توثيق SchoolSystem

هذه الحزمة مخصصة لفهم النظام والاستعداد للمناقشة، وليست مجرد وصف عام. تمت كتابة محتوياتها اعتمادًا على ملفات المشروع الفعلية، وبالأخص ملفات `UI`, `Services`, `DataAccess`, `Models`, `Security` و`Databass`.

| الملف | طريقة استخدامه |
|---|---|
| `دليل-المناقشة-الشامل.md` | المرجع الرئيسي؛ اقرأه لفهم المعمارية والاتصال وقاعدة البيانات والأمان وكل الوحدات. |
| `أسئلة-المناقشة-والإجابات.md` | ورقة مذاكرة مباشرة للأسئلة المتوقعة وإجاباتها. |
| `دليل-التشغيل-والاختبار.md` | خطوات تثبيت وتشغيل واختبار النظام واستكشاف الأخطاء. |
| `مخططات-النظام.mmd` | مخطط Mermaid للمعمارية وتدفقات الدخول والسندات والطلاب. |
| `SYSTEM_DOCUMENTATION.md` | التوثيق الهندسي الموجود سابقًا داخل المشروع. |
| `PROJECT_INVENTORY_AR.md` | جرد مكونات المشروع. |
| `OPERATIONS_AR.md` | العمليات التشغيلية والإجراءات. |
| `RBAC_FINAL_HANDOVER_AR.md` | تسليم نظام الأدوار والصلاحيات. |
| `TESTING_GUIDE_AR.md` | دليل الاختبار الموجود داخل المستودع. |
| `docs/validation-ui-inventory.md` | جرد تحقق الواجهات. |
| `docs/دليل-الاختبار-التشغيلي.md` | دليل الاختبار التشغيلي السابق. |

## ترتيب المذاكرة

اقرأ أولًا قسم المعمارية والاتصال بقاعدة البيانات في الدليل الشامل. بعد ذلك اقرأ الأمان والصلاحيات، ثم شاشة الطلاب والتسجيل، ثم السندات والتقارير. أخيرًا راجع ملف الأسئلة والأجوبة، وافتح ملفات المصدر المذكورة في نهاية الدليل لتتمكن من الإشارة إلى الكود أمام الدكتور.

## طريقة عرض المشروع في عشر دقائق

ابدأ بالهدف العام، ثم ارسم الطبقات الأربع. افتح `Program.cs` واشرح نقطة البداية، ثم `LoginForm` و`CurrentUser` لتوضيح الجلسة. افتح شاشة الطلاب واشرح دورة CRUD. بعد ذلك افتح التسجيل واشرح العام الدراسي والشعبة ومنع التكرار. اختم بالسندات لتوضيح الرقم التلقائي وقائمة الطرف والمعاملة ومنع التكرار. في النهاية اشرح أن كل زر يمر من Form إلى Service ثم Repository ثم SQL Server.

## ملاحظة مهمة

الشرح يصف الكود الموجود في نسخة التوثيق الحالية. إذا تغيرت أسماء ملفات أو قواعد البيانات في جهازك بعد ذلك، استخدم `git pull --ff-only origin main` ثم راجع النسخة الجديدة من الملفات قبل المناقشة.
