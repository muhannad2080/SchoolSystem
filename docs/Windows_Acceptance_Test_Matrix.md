# مصفوفة قبول Windows لنظام SchoolSystem

## الهدف

تُستخدم هذه المصفوفة بعد تنفيذ `git pull --ff-only origin main` و`Rebuild Solution` على جهاز Windows للتحقق من السلوك الفعلي لتطبيق WinForms وقاعدة SQL Server. يجب تسجيل النتيجة لكل حالة على أنها **ناجح** أو **فشل** مع إرفاق لقطة شاشة ورسالة الخطأ عند الفشل.

## المتطلبات السابقة

| العنصر | الإجراء |
|---|---|
| نسخة الكود | `git switch main` ثم `git pull --ff-only origin main` |
| البناء | `Build > Clean Solution` ثم `Build > Rebuild Solution` |
| قاعدة البيانات | التأكد من اتصال `SchoolDB` وتشغيل سكربتات المخطط والترحيلات المطلوبة |
| الحسابات | تجهيز مدير نظام، مستخدم بصلاحيات جزئية، ومستخدم بلا صلاحيات تشغيلية |
| البيانات | استخدام نسخة اختبارية، وعدم تنفيذ الاستعادة أو التفريغ على قاعدة الإنتاج |

## حالات القبول الأساسية

| المعرّف | المجال | خطوات الاختبار | النتيجة المتوقعة |
|---|---|---|---|
| WIN-01 | الدخول | أدخل بيانات صحيحة | فتح الشاشة الرئيسية وظهور اسم المستخدم |
| WIN-02 | فشل الدخول | أدخل كلمة مرور خاطئة ثلاث مرات لمستخدم غير مدير | تعطيل الحساب وإظهار رسالة القفل وتسجيل الحدث |
| WIN-03 | استثناء المدير | نفّذ محاولات خاطئة لحساب المدير | لا يُطبَّق قفل المحاولات على حساب المدير |
| WIN-04 | الصلاحيات | امنح مستخدمًا صلاحية واجهة واحدة فقط، سجّل الخروج ثم الدخول | تظهر الواجهة الممنوحة فقط |
| WIN-05 | إلغاء الصلاحيات | ألغِ صلاحية سبق منحها ثم أعد تسجيل الدخول | تختفي الواجهة أو الإجراء الملغى |
| WIN-06 | صلاحيات الإجراءات | امنح العرض دون الإضافة أو التعديل أو الحذف | يمكن العرض فقط وتُمنع أزرار وإجراءات التغيير |
| WIN-07 | البحث الفوري | اكتب أول حرف أو رقم في حقول البحث | تتغير النتائج مباشرة بعد أول إدخال |
| WIN-08 | البحث متعدد الكلمات | اكتب نصًا مثل `محمد أحمد` أو `Class A` | تُعرض الصفوف التي تطابق الكلمات عبر أعمدة البحث |
| WIN-09 | مسح البحث | امسح مربع البحث | تعود النتائج الكاملة ضمن الفلاتر الأخرى |
| WIN-10 | الطلاب | أضف طالبًا ثم حاول تكرار الهوية والهاتف | يُرفض التكرار برسالة واضحة |
| WIN-11 | التسجيل والقبول | اختر الطالب والصف والشعبة | تظهر الشعب الصحيحة ويُولّد العام الدراسي حسب التاريخ |
| WIN-12 | التسجيل المكرر | سجّل الطالب نفسه في العام نفسه مرتين | يُرفض التسجيل الثاني |
| WIN-13 | الفصول والقاعات | أضف فصلًا وقاعة دون إدخال الأرقام اليدوية | تتولد الأرقام والأكواد تلقائيًا وتظهر القوائم المنسدلة |
| WIN-14 | توزيع الطلاب | وزّع طالبًا نشطًا ثم حاول توزيع طالب غير نشط | ينجح النشط ويُرفض غير النشط |
| WIN-15 | الحضور والدرجات | سجّل حضورًا ودرجة لطالب نشط ثم لطالب غير نشط | يُقبل النشط وتُرفض العملية لغير النشط |
| WIN-16 | السندات | أنشئ سند قبض وصرف واختر الطرف من القائمة | رقم السند والطرف يظهران ويحفظان بصورة صحيحة |
| WIN-17 | النزاهة المالية | حاول حذف رسم مدفوع أو مصروف مرتبط بسند | يُمنع الحذف وتظهر علاقة الحماية |
| WIN-18 | الرواتب | أنشئ راتبًا ثم سجّل الصرف وحاول حذفه | يُمنع حذف الراتب المصروف |
| WIN-19 | سجل الأنشطة | نفّذ إضافة وتعديل وحذف وتسجيل دخول | تُسجل العملية والوقت والمستخدم وIP واسم الجهاز |
| WIN-20 | التصدير CSV | صدّر تقريرًا عربيًا | الملف UTF-8 مع BOM ويظهر العربي دون تشويه |
| WIN-21 | التصدير Excel | صدّر تقريرًا عربيًا وإنجليزيًا | الأعمدة كاملة، دون قص، والاتجاه مناسب للبيانات |
| WIN-22 | التصدير PDF | صدّر تقريرًا عربيًا | RTL صحيح، الخط مقروء، ولا يوجد قص للنص |
| WIN-23 | النسخ الاحتياطي | أنشئ نسخة إلى مسار مطلق صالح | تنشأ النسخة برسالة نجاح واضحة |
| WIN-24 | الاستعادة | استعد نسخة اختبارية مع قاعدة الهدف | تُطبق حماية `SINGLE_USER` وتعود القاعدة إلى `MULTI_USER` |
| WIN-25 | RTL والتصميم | افتح جميع النوافذ وغيّر حجمها | لا اختفاء للأزرار ولا تداخل أو قص للعناصر |
| WIN-26 | تسجيل الخروج | اختر تسجيل الخروج من الشاشة الرئيسية | تعود شاشة الدخول دون إغلاق التطبيق بالكامل |

## معايير النجاح

تُعد النسخة مقبولة إذا نجحت حالات الصلاحيات والدخول والبحث والماليات والتصدير دون أخطاء، ولم تظهر أخطاء تجميع، ولم تُسجّل بيانات مكررة أو قيود مالية قابلة للتجاوز. أي فشل يجب توثيقه برقم الحالة ولقطة الشاشة والنص الكامل للخطأ.
