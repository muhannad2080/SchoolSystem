# تقرير اختبار قبول صلاحيات الطباعة والتصدير

## نطاق الاختبار

راجع هذا الاختبار معالجات الإخراج في التقارير وسجل الأنشطة والطلاب والدرجات والرسوم، مع التأكد من أن صلاحية العرض لا تمنح تلقائيًا صلاحية الطباعة أو التصدير.

## الفحوص الثابتة

نجح `git diff --check` دون أخطاء تنسيق. كما أظهر الفحص أن ملفات الإخراج المعدلة تحتوي على حواجز `DemandAction` أو `DemandPermission` مرتبطة بالعملية المقصودة. لم يتم تنفيذ بناء WinForms داخل Linux؛ لذلك يجب اعتماد البناء وتشغيل الواجهات على Windows وVisual Studio.

## اختبار Windows المطلوب

بعد جلب الفرع `main` على Windows، يجب تنفيذ `Rebuild Solution` ثم تسجيل الدخول بثلاثة حسابات اختبار. الحساب الأول يملك صلاحية View فقط، ويجب أن يتمكن من القراءة دون ظهور نافذة الطباعة أو التصدير عند محاولة استخدامها. الحساب الثاني يملك View وExportExcel فقط، ويجب أن ينجح تصدير Excel ويفشل تصدير PDF والطباعة. الحساب الثالث يملك View وPrint وExportExcel وExportPDF، ويجب أن تنجح جميع العمليات.

يجب تنفيذ الاختبار باستخدام قاعدة `SchoolDB` وليس `master`، والتأكد من تطبيق هجرات RBAC وسجل التدقيق قبل تسجيل النتائج.

## أوامر المزامنة

```powershell
git switch main
git pull --ff-only origin main
```

ثم من Visual Studio:

```text
Build -> Rebuild Solution
```

ويجب حفظ أي أخطاء تشغيل أو لقطات RTL داخل سجل اختبار مستقل، لأن فحص Linux لا يغطي Designer أو Krypton Toolkit أو سلوك WinForms البصري.

## حدود النتيجة

هذا التقرير يثبت الحماية النصية والثابتة لمعالجات الإخراج المعدلة، لكنه لا يدّعي نجاح اختبار Windows الفعلي ما دام التنفيذ البصري والبناء الكامل يحتاجان بيئة Windows.
