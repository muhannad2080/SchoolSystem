# ملاحظات تنفيذ مركز التقارير

## مصدر المتطلبات
المتطلبات مأخوذة من الملفين المرفقين للمستخدم: `pasted_content.txt` و`pasted_content_2.txt` بتاريخ 2026-08-18.

## المتطلبات الأساسية
- تطوير `ReportCenterForm` بشكل احترافي RTL عربي دون تداخل أو عناصر مخفية.
- التقارير المدعومة فعليًا فقط، مع ربط Database → Repository → Service → UI.
- فلاتر ديناميكية حسب نوع التقرير، والتحقق من العام الدراسي والتاريخ وعدم إنشاء تقرير فارغ دون رسالة واضحة.
- حماية `Reports.View`, `Reports.Print`, `Reports.ExportPDF`, `Reports.ExportExcel`, `Reports.ExportCSV` باستخدام RBAC الحالي.
- PDF عربي RTL مع Header/Footer وصفحات A4 واتجاه ذكي عند الحاجة.
- Excel منظم بعناوين عربية وفلاتر وتجميد Header وAutoFit عند الإمكان.
- CSV بترميز UTF-8 BOM وتعامل صحيح مع الفواصل والاقتباسات والأسطر الجديدة.
- Print Preview وطباعة فعلية مع رأس التقرير والبيانات والتذييل.
- عدم استخدام SELECT * أو SQL غير معلم، وعدم إخفاء الاستثناءات، وتسجيل الأخطاء.
- اختبار البناء، جميع التقارير، الفلاتر، البحث، المسح، المعاينة، الطباعة، PDF، Excel، CSV، RTL، البيانات العربية والطويلة والفارغة والصلاحيات وتغيير الحجم.

## الحالة الحالية
- `UI/ReportCenterForm.cs` يحتوي تقارير الطلاب والمعلمين والقبول والتسجيل وتوزيع الفصول وحضور المعلمين والعقود والرواتب والمستخدمين والرسوم والدرجات والحركة المالية.
- الفلاتر الحالية: العام الدراسي، الصف، الشعبة، الحالة، التاريخ، البحث.
- `ReportCenterForm` يستخدم `ReportService`, `ClassService`, `ReportOutputHelper`.
- إصلاح CSV الحالي منفذ ومرفوع: صلاحية `Reports.ExportCsv` مع UTF-8 BOM.
- آخر commit متعلق بالتقارير: `56df423 Harden report CSV export permissions`.
- الاختبار الكامل على Windows وMSBuild غير متاح في Linux؛ يجب توثيق الحدود وعدم ادعاء نجاح اختبار WinForms بصريًا.
