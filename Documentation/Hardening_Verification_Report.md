# تقرير التحقق من مرحلة التحصين

## نطاق العمل

تم تنفيذ مراجعة مركزة لمسارات **البيانات المرجعية، العقود، الرواتب، الرسوم، السندات، التقارير، المستخدمين والصلاحيات** في مشروع SchoolSystem، مع الحفاظ على بنية المشروع الحالية المبنية على WinForms وطبقة الخدمات والمستودعات وقاعدة SQL Server.

## التغييرات المنفذة

| المجال | التغيير | الأثر |
|---|---|---|
| الشعب الدراسية | توحيد بيانات الشعب التجريبية والبيانات المستخدمة في تقارير الحضور إلى `Section A` و`Section B` و`Section C` و`Section D` | يمنع ظهور القوائم فارغة بسبب اختلاف القيم بين seed data والتقارير |
| الهجرات المرجعية | إضافة تحديث آمن للقيم العربية القديمة مع منع التكرار عند إنشاء الشعب | يحافظ على البيانات الحالية ويجعل التنفيذ قابلاً لإعادة التشغيل |
| العقود | إزالة طلب صلاحية العرض من الحساب الداخلي للراتب أثناء الإضافة والتعديل | المستخدم الذي يملك Add أو Edit لا يُرفض بسبب غياب View غير الضرورية للعملية |
| العقود القديمة | توحيد `TeacherContractService` مع `ContractService` | منع اختلاف قواعد التحقق والتدقيق بين مسارين متشابهين |
| الرواتب | إرجاع رقم السجل الجديد باستخدام `SCOPE_IDENTITY()` وتسجيله في Audit Log | يمنع تسجيل الراتب بالمعرف صفر |
| الرواتب | رفض صافي الراتب السالب وتاريخ الصرف المستقبلي والملاحظات الأطول من حد قاعدة البيانات | تقليل أخطاء البيانات والتعارض مع القيود |
| إدارة الصلاحيات | حماية زري منح ومنع جميع الصلاحيات بحارس مباشر ورسالة واضحة | منع التنفيذ الصامت عند غياب صلاحية إدارة الأدوار |

## اختبار Windows المطلوب

على جهاز Windows الذي يحتوي على Visual Studio يجب تنفيذ الأوامر التالية من مجلد المشروع:

```powershell
git switch main
git pull --ff-only origin main
msbuild SchoolSystem.sln /t:Build /p:Configuration=Debug /p:Platform="Any CPU"
```

بعد نجاح البناء، يجب فتح الواجهات التالية بصلاحيات مستخدم مختلفة: **إدارة المستخدمين والصلاحيات، إدارة العقود والرواتب، التقارير، الرسوم، السندات، المصروفات، التسجيل والقبول، وتوزيع الفصول**. يجب التحقق من عدم اختفاء الأزرار أو تداخلها في RTL، ومن ظهور رسالة صلاحية واضحة عند محاولة تنفيذ إجراء غير مسموح.

يجب أيضاً تطبيق هجرات قاعدة البيانات بالترتيب المعتمد في ملفات `Databass` على قاعدة `SchoolDB` وليس قاعدة `master`، ثم تشغيل ملف `Databass/Verify_SchoolSectionsSeed.sql` للتحقق من الشعب والصفوف والارتباطات.

## جولة فحص إضافية بتاريخ 2026-08-17

تمت مراجعة خدمات النسخ الاحتياطي والإعدادات، واكتُشف أن خدمة `DatabaseBackupService` كانت قابلة للاستدعاء دون حارس صلاحيات داخلي. أضيفت الآن صلاحيات `Settings.View` لاختبار الاتصال، و`Settings.Edit` للنسخ والاستعادة، مع الإبقاء على `Settings.Manage` كتوافق للخلف. كما تم توحيد حالة أزرار واجهة الإعدادات بحيث يظهر المستخدم القارئ البيانات دون تعديل، بينما تظهر أدوات التعديل والنسخ والاستعادة للمستخدم المخول فقط.

اكتشف الفحص أيضًا نصوصًا عربية مشوهة في `Seed_DemoReportingData.sql` نتيجة استبدال سابق داخل أسماء تجريبية، وتم تصحيح أسماء المعلم والطالب وولي الأمر. أُعيد فحص المستودع ولم تبقَ نصوص مشوهة من هذا النوع. القيم العربية الموجودة في ملفات الهجرة هي تحويلات مقصودة للقيم القديمة وليست بيانات تشغيلية جديدة.

آخر إصلاح مرفوع هو `513f789 Fix corrupted Arabic demo names`، والفرع المحلي متطابق مع `origin/main`.
